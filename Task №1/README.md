# ДЗ №1 — Изучение средств защиты ОС GNU/Linux

## Общая сводка

| № Раздела | Задание | Результат |
|---|---|---|
| 1 | Управление пользователями и группами | Создан пользователь `user1` с UID `1234`, группа `students`, срок действия пароля — 90 дней |
| 2 | SUID и процессы | Найдены SUID-файлы и процессы с `EUID=0` и `RUID` |
| 3 | Изучение механизма set-UID | Настроен `setuid` для копии утилиты `cat` и выполнено чтение файла, доступного только `root` |
| 4 | Изучение механизма привилегий | Аналогично с утилитой `cat`, только `chown` и для её копии установлена привилегия `cap_chown=ep` |
| 5 | Изучение механизма sudo | Пользователю `user1` предоставлено право изменять системное время с помощью `date`* |

## Файлы

| Файл | Описание |
|---|---|
| `suid.out` | Список найденных SUID-файлов |
| `processes.out` | Процессы с `EUID=0` и `RUID` |
| `stat.out` | Информация о владельцах, правах и атрибутах файлов |
| `getcap.out` | Установленные привилегии |
| `history.out` | История выполненных команд |
| `mephi-screenshot.png` | Скриншот бухгалтерского шифра обучающегося |
| `passwd` | Содержимое `/etc/passwd` |
| `group` | Содержимое `/etc/group` |
| `sudoers` | Конфигурация `/etc/sudoers` |
| `shadow` | Обезличенная версия `/etc/shadow`** |

## Примечания
*Задание выполнялось в 2 дня, так как в первый раз команда на использование sudo пользователем `user1` сработала, но не поменяла дату в системе навсегда, позже выяснил, что система автоматически включил NTP-подключение, которое автоматически меняло время на правильно. Лишь после отключения функции задание выполнилось.

**Файл `shadow` содержит обезличенные данные: хэши паролей заменены на `***`, в целях безопасности.
